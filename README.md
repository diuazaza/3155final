# IdeaLoop

IdeaLoop is a web-based platform for creative individuals to share and discover projects across multiple media (coding, 3D modeling, digital art, writing, music, crafts), request skill mentorship, and find project collaborators.

## Core Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript
- **Database & Migrations:** PostgreSQL with Kysely
- **Object Storage:** AWS S3
- **Testing:** Jest & Supertest
